# Ручные тесты PLC

Программы для Enviriot: вставить в редактор PLC узла, скомпилировать, загрузить, смотреть переменные
узла в Enviriot.

| Файл | Что проверяет | Ожидается |
|---|---|---|
| `selftest.js` | Целые и float операции, приведения, `Math.*`, NaN/Infinity/−0, API | `pass` = 36, `fail` = 0, `first` = 0; `online` = 1, `uptime` растёт |
| `merkers.js` | Обмен переменными со шлюзом, float в обе стороны | `y` = `k` × `x` после изменения `k`/`x` в Enviriot; `secs` раз в секунду, `blink` переключается, `t` — секунды с десятыми |
| `errors.js` | Остановка по ошибке и отчёт | `mode` = 1 → `PlcStop(0x86)`, 2 → `0x84`, 3 → `0x87` в журнале Enviriot; `cycles` перестаёт расти |
| `hdc1080.js` | TWI на шине 0, функции X13 1–4. Датчик HDC1080: SDA GPIO21, SCL GPIO22, подтяжки 4.7 кОм | `id` = 4176 (0x1050), `err` = 0; `temp`, `hum` — комнатные, раз в секунду |
| `dac_adc.js` | ЦАП и АЦП. Перемычка GPIO25 — GPIO34 | `pass` = 11, `fail` = 0; `maxerr` — наибольшая разница, мВ, на коде `worst`, где АЦП показал `worstmv`; затем при изменении `dac` — `mv` ≈ `expect` |
| `restart.js` | Выход не мигает при перезапуске. Перемычка GPIO2 — GPIO4 (счётчик фронтов) | `toggle` = 1 переключает светодиод GPIO2, `edges` растёт на 1; после остановки и запуска (или повторной загрузки) светодиод, `led` и `edges` не меняются |
| `io_errors.js` | Остановка по ошибкам ввода-вывода | `mode` = 1 → `PlcStop(0x8A)` (пин flash), 2 → `0x89` (девятый ШИМ), 3 → `0x8A` (`IN` без настройки), 4 → `0x89` (пин занят) |
| `clock.js` | Часы от Enviriot: `NowSeconds()`, `Today()` | `time` (ччммсс), `date` (ггммдд), `wday` — время и дата компьютера Enviriot |

После выключения питания программа запускается снова (хранится во flash): `selftest.js` опять даёт
`pass` = 36, `uptime` начинается с нуля.

Перед повторным запуском `errors.js` и `io_errors.js` верните `mode` в 0, иначе программа остановится сразу.

Пины настраивает `ConfigPin2(pin, mode, option)` (функция 31). Ввод-вывод в `dac_adc.js`, `restart.js` и
`io_errors.js` записан переменными с именами тегов X13 (`var Op2;`, `var Ae34;`): так их проверяли на плате,
но компилятор Enviriot с блоком `Pin` (`a6de46a`) теги для EspNode уже не принимает — эти тесты нужно
перевести на `Pin`. Тест UART — после переноса линии MQTT-SN на UART0.
