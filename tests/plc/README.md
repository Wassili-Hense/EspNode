# Ручные тесты PLC

Программы для Enviriot: вставить в редактор PLC узла, скомпилировать, загрузить, смотреть переменные
узла в Enviriot.

| Файл | Что проверяет | Ожидается |
|---|---|---|
| `selftest.js` | Целые и float операции, приведения, `Math.*`, NaN/Infinity/−0, API | `pass` = 36, `fail` = 0, `first` = 0; `online` = 1, `uptime` растёт |
| `merkers.js` | Обмен переменными со шлюзом, float в обе стороны | `y` = `k` × `x` после изменения `k`/`x` в Enviriot; `secs` раз в секунду, `blink` переключается, `t` — секунды с десятыми |
| `errors.js` | Остановка по ошибке и отчёт | `mode` = 1 → `PlcStop(0x86)`, 2 → `0x84`, 3 → `0x87` в журнале Enviriot; `cycles` перестаёт расти |

После выключения питания программа запускается снова (хранится во flash): `selftest.js` опять даёт
`pass` = 36, `uptime` начинается с нуля.

Перед повторным запуском `errors.js` верните `mode` в 0, иначе программа остановится сразу.
