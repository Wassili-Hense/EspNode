# Проверка ввода-вывода PLC на плате

Образы программ собираются без компилятора Enviriot и загружаются симулятором шлюза:

```
python tests/io/make_images.py
python tools/gw_sim.py COM4
plc upload tests/io/build/blink.bin 4
reg 50 Md0
```

Дно стека у всех образов — 4: мерке́ры `Md0`…`Md3` — данные программ. Мерке́р читается после `reg`, пишется
`pub <topic> <hex LE>`, например `pub 51 c8000000` — `Md1` = 200, если `Md1` зарегистрирован как 51.
Номера функций и режимов — [docs/plc-api.md](../../docs/plc-api.md), код образов — `make_images.py`.

| Образ | Перемычки | Мерке́ры | Ожидается |
|---|---|---|---|
| `blink` | — | `Md0` — состояние GPIO2 | Светодиод GPIO2 (devkit) мигает: 500 мс горит, 500 мс нет |
| `blink_fast` | — | `Md0` | Загруженный поверх `blink`: мигает чаще; при загрузке светодиод не гаснет и не вспыхивает |
| `pwm_count` | GPIO4 — GPIO5; GPIO18 замыкать на землю | `Md0` — счёт, `Md1` — GPIO18, `Md2` — запись задаёт счёт | `Md0` растёт на 100 в секунду; `Md1` = 1, при замыкании 0; запись `Md2` = 0 сбрасывает счёт |
| `adc_dac` | GPIO25 — GPIO34 | `Md1` — ЦАП 0…255 (запись), `Md0` — мВ | `Md0` ≈ `Md1` × 3300 / 255, точно до ~2450 мВ |
| `twi_scan` | датчик на GPIO21 (SDA) / GPIO22 (SCL), подтяжки 4.7 кОм | `Md0` — найденный адрес, `Md2` — устройств за проход | `Md2` — число устройств, `Md0` — адрес датчика; без устройств `Md2` = 0 |
| `uart_loop` | GPIO4 — GPIO5 | `Md0` — принятый байт, `Md1` — результат `UartPutByte`, `Md2` — принято байт | Раз в секунду `Md0` = секунды & 0xFF, `Md2` растёт на 1, `Md1` = 1 |
| `stream` | USB-UART адаптер: его RX — GPIO4, GND общий; 9600 8N1 | `Md0` — `NowSeconds`, `Md1` — результат `PrintFloat`, `Md2` — строк в журнал | Раз в секунду в адаптер строка `43215 12.33`: время и `getSeconds` / 3; раз в 10 с в журнале Enviriot уровнем Info — `t=40 v=   13.33`; `Md1` = 1 |
| `err_flash` | — | — | Отчёт об остановке со статусом `0x8A` (`ConfigPin` на пин flash) |
| `err_pwm9` | — | — | `0x89`: девятый канал ШИМ |

Перезапуск: после `blink` загрузить `adc_dac` — GPIO2 освобождается после первого цикла новой программы,
светодиод гаснет (вход без подтяжек). `STOP` (`plc stop`) оставляет выходы как есть.

`twi_scan` проверяет адрес за два цикла и больше: `TwiControl`, затем опрос `TwiStatus`. Без подтяжек на
шине обмен кончается таймаутом (до 200 мс на адрес), проход идёт дольше.
