- [ ] Свободные пины и порты — переменные узла. Описание xst одно на тип, а что свободно, зависит от `cfg`
  узла: сейчас занятый пин обнаруживается только при запуске программы (`0x89`). При подключении, вместе с
  типом устройства, узел публикует предопределённые объекты только для чтения:
  - `0xFFD8` — Array, 5 байт: пины, свободные для программы PLC, бит n байта n/8 — GPIOn. Нет flash
    (GPIO6–11), консоли отладочной сборки и пинов интерфейсов `cfg`.
  - `0xFFD9` — UInt8: свободные для программы порты UART (1/2), бит n — UARTn.

  Компилятор Enviriot пропускает пин, только если он есть и в группе xst (что умеет чип), и в маске узла
  (что свободно на этом узле). Пины — массив, а не число: в маске 40 бит, а побитовые операции JS 32-битные.
  Текущий Enviriot отвечает на незнакомый id PUBACK с отказом, узел код ответа не проверяет — совместимо.

  - `od_provider_t.info` — объекты провайдера PLC;
  - `plc_io_free_pins()`/`plc_io_free_uarts()` по резерву из `plc_io_init()`;
  - публикация сведений в `session_step()` по возрастанию id с пропусками (сейчас `idx++` обрывается на
    первом отсутствующем id);
  - в `E1S10.xst` добавить GPIO1/3, где они возможны;
  - тесты `io` и `e2e` (последовательность сессии).
